개요 (Overview)
1.1 제품 목적

부품 입고 검사 시 과거 불량 이력을 실시간으로 참조하여 검사자가 유의해야 할 불량 유형을 사전에 인지하고, 부품별 부적합 내용을 체계적으로 누적·관리하는 시스템

1.2 배경 및 문제 정의
  • 현재 부품 입고 검사 시 과거 불량 이력 정보가 검사자에게 즉시 제공되지 않음
  • 동일 부품에서 반복 발생하는 불량 유형을 사전에 인지하지 못해 검사 누락 발생
  • 부적합 데이터가 분산 관리되어 부품별 품질 트렌드 파악이 어려움
  • 차수별 입고 시 이전 차수의 불량 이력이 검사 기준에 반영되지 않음
1.3 목표
  • 부품별 불량 이력 데이터를 누적 저장하고 검색 가능한 구조로 관리
  • 신규 입고 검사 시 해당 부품의 과거 불량 유형을 자동으로 알림
  • 부품별 부적합 내용을 리포트 형태로 정리 및 출력
  • 반복 불량 부품에 대한 관리 강화 체계 수립
